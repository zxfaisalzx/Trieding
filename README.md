# التزام

تطبيق أندرويد (Kotlin + Jetpack Compose) يساعدك تلتزم بخطة البيع: تحط أهداف البيع ودفعات الوقف وقت الشراء، والتطبيق يتابع السعر ويرفع الوقف تلقائياً ويضيّقه كلما قرب السعر من الهدف، ويرسل لك تنبيه وقت التنفيذ.

> أداة انضباط تنفّذ قواعدك أنت، وليست نصيحة مالية.

## التثبيت

كل ما يتحدث فرع `main` يبني GitHub التطبيق تلقائياً وينشره في صفحة Releases باسم `iltizam.apk`.
افتح صفحة **Releases** في المستودع من جوالك، حمّل `iltizam.apk`، واسمح بالتثبيت من مصادر غير معروفة.

## الإعداد

1. سجّل مجاناً في [finnhub.io](https://finnhub.io/register) وانسخ الـ API Key.
2. في التطبيق: الإعدادات ← الصق المفتاح ← حفظ وتجربة.

## الوقف المتحرك الذكي

الوقف يُحسب كنسبة تحت أعلى سعر وصله السهم بعد الشراء، ولا ينزل أبداً:

| المرحلة | الوقف |
| --- | --- |
| قبل نص الطريق للهدف الأول | الوقف اللي حددته |
| 50% إلى 80% من الطريق | 15% تحت أعلى سعر |
| 80% حتى الهدف الأول | 10% |
| بعد تنفيذ الهدف الأول | 8% |
| بعد تنفيذ هدفين | 7% |

إذا قسمت الوقف لدفعات (مثلاً نص الكمية عند 30 والنص عند 27)، أعلى دفعة تتبع الوقف المتحرك والباقي يحافظ على نفس الفرق النسبي.

مثال (`EngineTest`): 200 سهم بـ 29، بيع 50 عند 40 و50 عند 42، القمة 45 ← الوقف 41.85 والربح المحقق 2,485$.
